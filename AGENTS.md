# Agent Instructions

This repository is registered with Yaup as `pane` and is checked out at `<yaup>/repos/pane` in a local Yaup checkout, so the Yaup root is `../..` from here.
Yaup is the authoritative source for shared agent rules, guardrails, playbooks, and skills.

Before doing ticket work here, read and follow (paths relative to the Yaup root):

- `policies/core.md`
- `policies/rules.yaml`
- the relevant skill in `skills/`
- the relevant playbook in `playbooks/`

Repository-local instructions may add project-specific context, but they must not weaken or override Yaup rules.
If instructions conflict, Yaup wins.
